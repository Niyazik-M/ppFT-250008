# Лабораторная работа №2 — GitHub

1. Прослушать курс (3 урока)  https://www.youtube.com/playlist?list=PL3LQJkGQtzc5rDeb7FjACNb6sOW300yA0  "GitHub для новичков"
2. Посмотреть видео "Git и GitHub Курс Для Новичков" https://vkvideo.ru/video-182420474_456239398
3. Почитать теоретический материал:

Подробно: https://skillbox.ru/media/code/chto-takoe-github-i-kak-im-polzovatsya/
Кратко: https://habr.com/ru/articles/541258/

4. Потренироваться для закрепления теории: Пройти первые 4 урока на сайте https://learngitbranching.js.org
5. Зарегистрироваться на GitHub.
6. Создать git-репозиторий.
7. Загрузить проекты заданий Лаб. работы №01 (3 проекта/папки в один репозиторий).
8. Добавить к репозиторию файл README.md в формате Markdown со следующей информацией (пример оформления файла приведен): исполнитель,
   название и формулирование задания,
   описание того, в какой среде программирования можно открыть проект, какой файл проекта следует открывать,
   как запускать вашу программу, и как ей пользоваться,
   скриншоты тестов.
   Ссылка на справочник по синтаксису README.md https://github.com/GnuriaN/format-README
